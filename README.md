# PM Surya Ghar Muft Bijli Yojana — Trimurti Solar Systems

Official solar web application and management platform for Loom Solar / Trimurti Solar Systems (Malda District, West Bengal).

## Features
- **Online Solar Application**: Comprehensive multi-step subsidy application form with auto-calculation, dealer assignment, and document upload.
- **Applicant Dossier & QR Code**: Each submitted form generates an official application with a unique QR code and reference ID.
- **Official PDF Generation**: Export complete filled PM Surya Ghar subsidy application forms directly into official printable PDF documents.
- **User Authentication & Dashboard**: Secure customer sign-in, mobile/DOB account recovery, and real-time live application status tracking.
- **Admin Command Center**: Real-time management of all incoming applications, status updates, remark notes for applicants, and filtering by block/GP.
- **Block & GP Directory**: Interactive directory covering all 15 blocks and 146 Gram Panchayats in Malda District.

## Tech Stack
- **Frontend**: React (Vite), React Router
- **Backend & Database**: Supabase (PostgreSQL with real-time replication & Row Level Security)
- **Styling**: Vanilla CSS with responsive design system
- **Deployment**: Vercel & GitHub
